📖 Como Usar

1. Formato do Markdown: 
# Nome do Projeto

ID: com.app.meu_projeto
API Min: 21
API Max: 33
Orientação: portrait

## Descrição

Descrição do projeto aqui

## Pastas

- src
- public
- assets

## Arquivos

- **index.html**
<!DOCTYPE html>
<html>...

- **style.css**
body { ... }
2. Campos Reconhecidos:
  • 📋 Nome: Primeira linha com #
  • 🔗 ID: Campo "ID:"
  • 📱 API Min: Campo "API Min:"
  • 📱 API Max: Campo "API Max:"
  • 🔄 Orientação: Campo "Orientação:"
  • 📝 Descrição: Seção "## Descrição"
  • 📁 Pastas: Seção "## Pastas"
  • 📄 Arquivos: Seção "## Arquivos"
3. Resultado:

Um HTML interativo onde você pode:

  • ✅ Editar arquivos
  • ✅ Criar pastas e arquivos
  • ✅ Copiar conteúdo
  • ✅ Ver estatísticas
  • ✅ Gerar scripts para PC
