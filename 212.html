📦 RAIO-X do computador e do projeto (.bat)

Esta página já traz o projeto inteiro guardado dentro dela (4 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Abra esta página no computador (dois cliques nela) e toque no botão verde. O RAIO-X.bat vai para a pasta Downloads. Se o Chrome perguntar, escolha Manter.
  2. Copie o RAIO-X.bat para dentro da pasta do projeto que você quer examinar.
  3. Dê dois cliques nele. Se o Windows avisar "protegeu o computador": Mais informações → Executar assim mesmo.
  4. Ele só olha, não muda nada. No fim abre o Bloco de Notas com o relatório: programas instalados, quem usa cada porta, comandos do projeto, restos da Replit e rotas de API.
  5. No fim ele pergunta se quer testar o build. S = sim, N = não.
  6. Se o botão não baixar, me avise: eu te mando o texto para colar no Bloco de Notas.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.
